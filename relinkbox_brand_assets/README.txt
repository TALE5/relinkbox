Relinkbox brand assets (draft)

Files:
- svg/relinkbox-wordmark.svg: transparent vector wordmark; "Relink" light grey and "box" Princeton Orange.
- svg/relinkbox-monogram.svg: standalone transparent R monogram.
- svg/relinkbox-app-icon.svg: rounded-square application icon.
- png/: transparent PNG exports where available.
- app_icon/relinkbox.ico: Windows executable icon where rasterization succeeded.

Palette:
- Princeton Orange: #FF910F
- Light lettering: #E8E8E8
- Icon background: #202020

Typography:
The SVG wordmark uses the font stack "Inter Display, Helvetica, Arial, sans-serif".
For consistent appearance, bundle Inter Display with the app or convert the wordmark text to outlines in a vector editor.
The SVG assets are transparent except the app icon, which intentionally has a dark tile.
These are initial brand drafts, not final trademark artwork.
